# Lucknowi Nazakat

| Folder   | Run                                   | URL                    |
|----------|---------------------------------------|------------------------|
| backend  | `npm install` then `npx nodemon app.js` | http://localhost:3001  |
| client   | `npm install` then `npm run dev`        | http://localhost:5173  |
| admin    | `npm install` then `npm run dev`        | http://localhost:5174  |

Create `backend/.env` from `backend/.env.example` first. Run each in its own terminal.
