# Lucknowi Nazakat: admin panel

```bash
cd admin
npm install
npm run dev        # http://localhost:5174 (port must be free)
```
Backend must be running on port 3001. Only users with role "admin" can sign in.
If port 5174 is already in use, stop the other dev server before starting the admin app.
Pages: Dashboard, Products (list, add, edit, delete), Categories (add, edit, delete).
